# LUT-Constrained K-Means 颜色量化（高精度颜色匹配）

## 用法

“高精度颜色匹配”把量化后的颜色限制在 LUT 中，避免普通 K-Means 先生成任意 RGB、再匹配到可打印颜色时产生额外色差。高级设置中的复选框默认关闭；耗材档案使用自己的材料匹配流程。

```python
quantize_colors(
    rgb,
    n_colors,
    use_lut_constrained=True,
    lut_lab=lut_lab,
    lut_rgb=lut_rgb,
    lut_tree=lut_tree,
)
```

调用时同时提供 `lut_lab`、`lut_rgb` 和 `lut_tree`；缺少有效 `lut_lab` 或 `lut_tree` 时回退到普通量化。普通路径支持 `mask`：掩码外像素不参与聚类并保留原 RGB；LUT 约束路径暂不支持掩码，会明确报错。

`skip_post_blur` 和 `lut_fingerprint` 仅在公开入口保留兼容接收，当前调用方无需传入。量化后模糊步骤已经删除，旧的模糊环境变量不再生效；预处理滤波与孤立像素清理仍各自负责降噪。

## 当前算法

1. 颜色数不超过 LUT 条目数；覆盖整个 LUT 时直接进行最近邻映射。
2. 大图使用现有的 `KMEANS_PIXEL_THRESHOLD` 预缩放做聚类，再映射回原图。
3. 把 RGB 转为 Lab，在 Lab 空间计算颜色距离。
4. 按图像中各 LUT 颜色的像素权重选择初始中心；后续中心结合最近距离与像素权重选择。
5. 用 KDTree 分配像素、更新聚类中心，并将中心投影回 LUT。尝试三组初始中心，每组最多迭代二十次，保留平方误差最小的结果。
6. 输出 LUT 中的 RGB；不再进行可能合成新颜色的后量化模糊。

内部函数从权威 `lut_lab` 建立 KDTree，调用方传入的树配置不会改变等距选择或缓存语义。最近距离查询避免构造完整的像素数 × 聚类数距离矩阵。

## 缓存

缓存保存少量最近输入和输出的副本。命中条件比较算法参数及实际数组内容；LUT 路径同时比较图片、Lab 和 RGB 数组，普通路径比较实际量化输入。调用方提供的指纹不参与判断。

返回值也是副本，因此调用方修改结果不会污染后续缓存；更换图片、LUT 或量化模式时，不能返回旧输入的结果。

## 界面与处理链路

高级设置、转换请求和 worker 将 `use_lut_constrained` 传给 `LuminaImageProcessor`，由 `_prepare_high_fidelity_images` 调用量化器。颜色与材料层匹配、透明区域和最终建模继续由原有流程处理。

启用时，后端关闭色相保护匹配，前端禁用对应复选框并显示原因；关闭时恢复普通量化和色相保护选项。

## 回归验证

现有测试检查 LUT 颜色归属、颜色数量、输入变化后的缓存正确性、确定性、缺少 LUT 时的回退，以及公开旧参数的兼容性。相关检查可运行：

## 历史 Benchmark

下表保留首次引入功能时的测量，说明当时采用 LUT 约束的依据。之后距离查询和缓存实现已有变化，这些数值不代表当前版本的测量；需要比较当前效果时使用 `scripts/benchmark_lut_constrained.py`。

当时使用 `LUT_Stress_Test_HD.png`（1920×2160），比较普通量化后再匹配 LUT 与 LUT 约束量化。

> 旧路径量化后的颜色本身不在 LUT 中，事后 LUT 匹配引入 **11–23 ΔE** 的附加损失（LUT-match penalty）。新路径的聚类中心本身就是 LUT 条目，端到端 ΔE 在所有格子上都更低。

### 速度

| LUT 大小 | 36–256 色 | 1024 色 |
|----------|-----------|---------|
| 1024 条目 | 新路径 1.05–1.11×（略慢 5–11%） | 1.10–1.30× |
| 1296 条目 | 0.89–1.19× | 1.30–1.40× |
| 2738 条目 | 0.96–2.22×（72 色时最慢） | 1.80–2.00× |

当时普通量化后的颜色再匹配 LUT 会增加 11–23 ΔE，约束量化在表中各组输入上降低了最终色差。速度随 LUT 大小、图片和颜色数量变化，应使用实际输入判断是否值得开启。

## 保留的修复依据

曾出现 `'a' and 'p' must have same size`：空聚类重采样把像素距离数组当作 LUT 采样概率，两个数组长度不同。空聚类现在直接从 LUT 中选择新中心，不再使用长度不匹配的像素概率。
