# SVG 平滑轻量预览、模型覆面真实颜色与实时尺寸设计

## 结论

本次修复把三个已经互相影响的前端预览问题放在同一个独立 PR 中处理：

1. 原生 SVG/Vector 的普通 3D 预览改用解析后的矢量轮廓生成轻量网格，不能再从降采样像素掩膜反推边界。
2. 模型覆面仍使用现有的平滑纹理预览，但颜色预览完成后必须显示 LUT、配方叠色、替色和撤销/重做后的干净结果，不能一直显示原始上传颜色。
3. 修改目标尺寸恢复为前端即时缩放，不销毁 session，也不重新请求预览；所有依赖模型边界的创意预览必须跟随缩放。

精确打印几何继续只属于 3MF 生成链路。本次不修改 3MF 网格、切片 coverage、独立壳体、拓扑、材料身份或打印质量。

## 已确认的根因

### 普通 SVG 的像素感

原生 SVG 在 `VectorProcessor` 中已经解析成 Shapely 矢量几何，但当前异步轻量 GLB 没有消费这些几何。预览链路先以 10 px/mm 构建 `matched_rgb` / `mask_solid`，大图再降到约 30 万像素，然后从像素掩膜提取轮廓并挤出。

因此当前 GLB 虽然不再逐像素生成体素，却仍然是“像素轮廓的挤出”。R4C1 的 1110×2407 缓存还会在 GLB 阶段继续降采样，所以 SVG 曲线会出现可见台阶。

### 模型覆面显示原始颜色

模型覆面选择器没有加载普通预览 GLB。它把 `Scene3D` 传入的 `imagePreviewUrl` 画入动态 CanvasTexture，再贴到用户选择的模型表面。对于 SVG，`imagePreviewUrl` 是原始文件的 Blob URL，所以浏览器能够平滑抗锯齿，但完全绕过了 LUT 匹配、配方叠色和后续替色。

状态中已经存在合适的颜色来源：

- `previewBaseImageUrl` 是当前干净的、无选区高亮的显示结果；
- 初次预览时它指向像素对齐的 `preview_rgba`；
- 区域替色、批量替色、自定义配方、撤销和重做都会更新它；
- `previewImageUrl` 可能暂时指向选区高亮图，不能用作覆面纹理。

### 修改尺寸会重新生成预览

实时 XY 缩放能力仍在 `Scene3D` / `InteractiveModelViewer` 中。回归来自 PR #519 引入的自动预览输入键：`target_width_mm` 被当成所有预览参数的一部分，宽度变化会立刻清空当前 session 和 GLB，再延迟请求新预览。

这覆盖了原有的即时缩放语义，也与 #586 已确定的“尺寸属于前端实时显示状态”契约冲突。

## 方案比较

### 方案 A：提高 segmented GLB 的像素分辨率

优点是改动小。缺点是曲线仍然受像素网格限制，文件、内存和生成时间会继续增长；放大后仍能看到台阶。该方案不解决根因，拒绝采用。

### 方案 B：普通 SVG 也只使用一张平滑顶面贴图

模型覆面已经证明这种方式平滑且轻量。但普通 3D 预览还要表达逐色高度、浮雕、描边、景泰蓝线、单双面和轮廓侧壁。单张平面纹理会把这些三维语义压平，只适合作为模型覆面的平面排版预览，不能成为普通 SVG 的唯一几何来源。

### 方案 C：矢量轻量网格 + 正确的覆面纹理（采用）

普通 SVG 从已经裁剪并完成颜色匹配的矢量 shape 构建显示级描述，只挤出浏览器需要的轮廓和高度身份。模型覆面继续使用纹理，但切换到干净的叠色预览图。两条路径共享颜色结果和 session 生命周期，但不强行共享错误的几何表达。

该方案同时满足平滑、轻量、创意功能和真实颜色。

## 架构设计

### 1. 原生 Vector 显示描述

在原生 Vector 预览分析完成后，生成一个 session-bound 的轻量显示描述。描述只包含浏览器需要的信息：

- 已完成遮挡裁剪的 Polygon / MultiPolygon 轮廓；
- 画布边界、缩放和坐标方向；
- 当前显示颜色；
- 稳定的高度身份；
- 可见轮廓和底板 silhouette；
- 描边、拼图等前端定位所需的 bounds 锚点。

描述以版本化、可校验的数据结构保存。几何使用 WKB 或等价的明确序列化格式，不把任意 Python 对象直接暴露给前端。描述文件与 preview session 一起注册和清理，不允许跨 session 复用。

### 2. 矢量轻量 GLB 构建

异步 GLB worker 检测到有效的原生 Vector 描述时，优先走矢量显示构建器：

1. 对显示容差以内的冗余点做拓扑保持型简化；
2. 直接三角化并挤出 Polygon，不经过像素掩膜；
3. 按当前显示颜色和高度身份合并兼容部件；
4. 保留 `color_RRGGBB`、`backing_plate` 和 `preview_canvas_bounds` 等前端契约；
5. 使用当前轻量 GLB 的异步 job token、FileRegistry、TTL 和 session 清理流程发布。

显示简化容差必须以毫米定义并有上限；不得使用会跨越孔洞、合并独立壳体或改变可见拓扑的简化结果。若描述缺失、版本不兼容、文件过期或几何校验失败，只能对当前 session 安全降级到现有 segmented 预览，不能读取其他 session 的描述。

### 3. 编辑后的平滑重建

全局颜色替换仍可先由前端即时改材质。需要服务端确认的区域替色、配方替换和撤销/重做完成后，异步构建器用当前 `matched_rgb`、`height_identity_rgb` 和矢量描述重新归类 shape，再生成同一套平滑网格。

像素缓存只用于判断一个既有矢量连通部件当前属于什么显示颜色或高度身份，不再作为网格边界。这样替色结果与 2D 预览一致，同时边界仍来自 SVG 矢量轮廓。

如果一次编辑确实把同一个矢量连通部件分成多个不同结果，采用与最终原生 Vector 生成链路相同的组件投影规则；不能静默串用旧颜色或旧几何。

### 4. 创意功能

矢量轻量 GLB 继续交给现有 `InteractiveModelViewer`。因此：

- 浮雕和逐色高度继续按颜色/高度身份调整 Z；
- 描边和景泰蓝继续从平滑源网格推导轮廓；
- 钥匙扣、冰箱贴和拼图继续使用 bounds 与前端程序化代理；
- 双面继续在前端镜像轻量颜色层；
- 涂层、底板厚度等继续使用实时显示参数；
- 最终 3MF 不消费显示简化网格。

普通 raster、高保真高度图和非原生 Vector 路径继续使用现有 segmented GLB，不改变行为。

### 5. 模型覆面纹理来源

新增一个明确的覆面纹理选择规则：

```text
存在当前 session 的 previewBaseImageUrl -> 使用干净的叠色/替色结果
尚未完成颜色预览                    -> 使用原始 imagePreviewUrl 供选面与排版
session 被关闭、切换或失效           -> 清除旧 previewBaseImageUrl，禁止继续显示
```

不能使用 `previewImageUrl`，因为它可能包含颜色选择、连通区域或渐变区域的临时高亮。

CanvasTexture 的动态分辨率、SVG 浏览器抗锯齿、LinearFilter 和资源释放逻辑保持不变。

### 6. 尺寸即时缩放

`target_width_mm` / 派生高度不再进入自动预览的重建身份。尺寸变化只更新前端目标尺寸，并通过现有 `computeScaleFactor()` 缩放当前轻量模型。

同时补齐依赖边界的创意功能：

- 相机 near/far 和最大轨道距离使用缩放后范围；
- 钥匙扣锚点跟随缩放后的模型边界，但钥匙扣自身毫米尺寸不被放大；
- 冰箱贴中心位置跟随模型缩放，磁铁实体仍保持设置的毫米尺寸；
- 拼图、描边、景泰蓝位于模型缩放 group 内，继续同步缩放；
- 拖拽写回的偏移继续使用模型本地毫米坐标。

尺寸变化后点击生成时，后端仍按最新尺寸生成精确 3MF。旧尺寸 preview GLB 只在浏览器中实时缩放；其 fingerprint 不得冒充新尺寸的可复用生成资产。

## 生命周期与竞态

- Vector 描述、GLB 和叠色 PNG 都属于 preview session，随 session 关闭清理。
- 最终 3MF 仍是独立 TTL 下载资产，关闭源 session 后继续可下载。
- 每次异步平滑 GLB 构建继续使用 session id + job token；旧任务完成时不得覆盖新任务 URL。
- 覆面纹理只能选择当前 store/session 持有的 `previewBaseImageUrl`；切换图片或 session 时必须立即失效。
- 预览 GLB 尚未完成时点击生成，浏览器继续等待/显示轻量预览，不能回退打印精确 GLB。

## 测试设计

### 后端

- 矢量描述保留曲线轮廓、孔洞、独立部件和 bounds；
- 矢量 GLB 顶点不再锁定在预览像素网格上；
- 简化后的 Hausdorff/面积误差在显示容差内，孔洞与组件数不变；
- 编辑后的颜色归类使用当前缓存，但 footprint 仍来自矢量描述；
- 无效、过期、外部 session 描述安全降级且不串模型；
- raster、高保真、material archive 和模型覆面路由不误入错误构建器；
- 原生 Vector 生成和 3MF 相关既有测试保持通过。

### 前端

- 模型覆面在预览完成前使用原图，完成后切换 `previewBaseImageUrl`；
- 替色、配方和撤销/重做更新覆面纹理；
- 选区高亮变化不污染覆面纹理；
- session 切换/关闭后不显示旧纹理；
- 修改尺寸不调用 preview、不清空 session/GLB，并立即改变模型 scale；
- 钥匙扣和冰箱贴在缩放后仍正确贴合，实体毫米尺寸不变；
- raster 路径仍能实时缩放且不改变 GLB 来源；
- Generate 期间始终保持 quick-preview 资产所有权。

所有非 watch 前端测试必须通过 `python scripts/run_vitest.py` 运行。

### R4C1 真人流程

使用已确认的 R4C1 SVG，分别验证：

1. 上传后等待预览完成，再生成；
2. 轻量 GLB 尚未完成时立即生成；
3. 修改尺寸、替色、修改配方后观察即时预览；
4. 开启浮雕、描边、景泰蓝、钥匙扣、冰箱贴、拼图和模型覆面逐项检查。

记录浏览器实际 URL、Content-Length/文件大小、GLB 顶点/面数、加载耗时、峰值内存和截图。普通 SVG 的曲线必须无像素台阶，颜色区域和透明孔洞完整；模型覆面必须显示叠色后的颜色。必要时用 Bambu Studio / OrcaSlicer 对比 3MF，确认对象、材料、拓扑和切片结果未变化。

## 验收标准

- R4C1 普通 SVG 3D 预览曲线平滑，且使用 session-bound 轻量预览资产；
- 轻量资产不大于当前约 20.51 MB 基线，并以明显减少网格量为优化目标；
- 模型覆面在颜色预览后显示真实叠色/替色结果，同时保留当前平滑度；
- 尺寸修改无预览请求、无 loading 闪烁、无 session 重建；
- 所有创意功能仍在轻量预览上正确定位和更新；
- 打印精确 GLB 不再成为浏览器回退来源；
- 3MF 内容、打印质量与下载生命周期无变化；
- 后端聚焦 pytest、前端 Vitest、smoke、日志质量检查和 R4C1 两种时序验证通过。

## 非目标

- 不修改 3MF writer、切片 coverage、独立壳体或打印拓扑；
- 不把 raster/位图轮廓伪装成矢量；
- 不在本 PR 重写整个 Three.js 查看器；
- 不自动合并 PR。
