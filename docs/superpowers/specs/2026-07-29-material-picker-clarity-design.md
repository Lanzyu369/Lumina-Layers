# 耗材选择器清晰度与档案收藏设计

## 结论

耗材选择器改为更大的分层浏览界面：第一层按材料类型筛选，第二层按品牌筛选，
内容区使用双列耗材卡片。所有品牌平等展示，不再使用“更多品牌”折叠现有品牌。

同一种实体耗材可以包含多位作者上传的档案，但这些档案只做归组，不做系统推荐。
用户可以独立收藏任意数量的作者档案，也可以自由混选 PLA、PETG 或其他材料类型。
当选中项跨类型时，界面即时提示兼容风险；点击完成后再做一次客观确认，不阻止用户
继续。

这次设计不依赖名称猜测来判断材料类型、作者或同款关系。前后端需要补充结构化字段，
旧档案缺少字段时保守显示为未分类或独立档案，避免错误合并。

## 当前问题

现有弹窗宽度约为 `max-w-md`，品牌与耗材都堆叠在一列中。品牌展开后，用户需要在
很长的列表里滚动；材料名称、品牌、色点和色差处于同一视觉层级，难以快速扫读。

当前流程还存在以下问题：

1. PLA 与 PETG 混在品牌列表里，用户看不到当前选择是否跨材料类型。
2. 混选后可以直接完成，界面没有温度和层间粘结方面的兼容提示。
3. 同款耗材的不同作者档案被当作互不相关的耗材重复展示。
4. 作者常被写进名称字符串，API 没有稳定的作者和实体耗材标识。
5. 品牌分组把一部分品牌放入“更多品牌”，会造成不必要的品牌权重差异。
6. 现有收藏能力只覆盖其他资源，耗材档案没有独立收藏入口。

## 目标与非目标

### 目标

- 让用户先理解材料类型，再选择品牌与具体耗材。
- 在桌面端提高信息密度，同时保持名称、作者、色差和状态可扫读。
- 允许跨类型选择，但在提交前清楚说明客观风险。
- 将同一实体耗材的作者档案归在一起，保留每份档案的独立身份。
- 允许用户按个人意愿收藏任意档案，不引入系统优先级。
- 对旧数据采取保守兼容策略，不因模糊名称造成错误归组。

### 非目标

- 不判断 PLA 与 PETG 是否一定可以或不可以共同打印。
- 不提供“官方档案”“首选档案”或自动推荐排序。
- 不根据收藏数量改变系统默认选择。
- 不在本次改动中清洗、删除或覆盖已有耗材档案。
- 不改变下游转换流程接收的已选档案目录标识。

## 信息架构

### 1. 材料类型导航

弹窗顶部在搜索框下方显示固定标签：

- `收藏`
- `全部`
- `PLA`
- `PETG`
- `其他`

`其他`包括 ABS、ASA、TPU 等非 PLA/PETG 类型，也包括缺少结构化类型的旧档案；
缺失类型的档案显示“未分类”标记。标签只筛选结果，不会清除当前已选项。

当前仓库内的旧档案尚未写入结构化类型。为避免第一版上线后所有旧档案都落入“其他”，
兼容层可以在 `material_type` 缺失时，只识别名称或目录中的完整 `PLA`、`PETG`
英文标记用于本次界面筛选，并把来源标记为 `legacy_name`。这只是可撤销的展示分类：
不回写档案、不参与实体耗材归组，也不把其他相似词猜成材料类型。档案一旦带有显式
`material_type`，显式值始终覆盖兼容结果；没有精确标记的旧档案仍显示“未分类”。

搜索同时匹配耗材名称、品牌、颜色或类型以及作者。搜索结果仍保留实体耗材归组，
不会把同一组中的作者档案拆散。

结果区提供“名称”和“最近使用”两种排序。默认使用名称排序；“最近使用”只根据用户
实际提交过的档案时间调整实体耗材卡片顺序，不自动选择上次使用的作者档案，也不改变
收藏状态。同一实体耗材有多份档案时，以其中最近一次实际使用时间作为卡片排序时间。

### 2. 品牌导航

桌面端左侧使用独立、可滚动的品牌栏，顺序为：

1. `全部品牌`
2. `未分组`
3. 所有实际品牌，按本地化名称排序

品牌栏必须显示全部品牌，不设置“常用品牌”“推荐品牌”或“更多品牌”。任何品牌，
包括 Lumina 当前已有档案较多的品牌，都使用相同的字号、颜色和计数样式。

仅大小写、全半角或首尾空格不同的品牌名可在展示层合并，例如 `JAYO` 与 `jayo`。
归一化只影响品牌导航与计数，不用于推断两份耗材档案是否属于同一实体耗材。无法
确定的相似品牌名保持分开。

### 3. 耗材内容区

桌面端内容区使用两列卡片。每张实体耗材卡片至少显示：

- 颜色色点
- 品牌与耗材名称
- 材料类型
- 已选状态
- 作者档案数量，例如“3 份档案”
- 单档案时的作者与关键质量信息

名称最长显示两行；色差、验证次数等辅助信息不得挤压主名称。卡片点击区域与选择控件
都应达到至少 44×44 CSS 像素的可操作尺寸。

### 4. 选中卡片视觉状态

耗材选中状态由整张卡片承担，不再在单档案卡片右侧重复显示空心圆或蓝色对勾。选中的
单档案卡片，以及已选中某位作者档案的多档案外层卡片，统一使用：

- 极淡的蓝色表面底色；
- 1px 内描边，避免与相邻卡片或鼠标悬浮边框发生位置重叠；
- 轻量的蓝色阴影；
- 点击新选中时仅播放一次约 180ms 的淡蓝光过渡。

一次性过渡只在用户本轮主动选中档案时触发；打开弹窗时已经选中的卡片不播放，取消
选择也不播放。效果只改变蓝光强度，不使用缩放、位移、呼吸或循环动画，并在系统启用
“减少动态效果”时停用。

鼠标悬浮态与键盘焦点态继续承担各自语义：指针点击后不保留内部焦点框，键盘导航时
仍显示可见焦点环。单档案卡移除圆圈与对勾后，整张主要内容区继续作为选择按钮，并
保留 `aria-pressed` 与选择/取消选择的可访问名称。多作者档案展开区里的单选控件继续
保留，因为它用于明确区分具体作者档案。浅色与深色主题都使用现有 Tailwind 色阶与
设计令牌，不引入硬编码颜色。

## 同款耗材与作者档案

### 归组规则

同款归组只接受稳定的 `material_product_id`。两份档案即使品牌、名称和颜色完全相同，
只要缺少相同的实体耗材标识，就继续显示为两个独立耗材卡片。

禁止仅依赖以下信息自动合并旧档案：

- 名称中是否包含相同文字
- 作者后缀是否相似
- 十六进制颜色是否相同
- 品牌与类型是否看起来一致

旧档案可以在后续数据维护中人工建立实体耗材映射；在此之前，保守地保持独立。

### 档案展开与选择

有多份档案的卡片显示档案数量并可展开。展开区逐行展示：

- 作者名称
- ΔE
- 验证次数
- 更新日期
- 收藏星标
- 用于本次打印的档案单选项

选择某个实体耗材时：

- 只有一份档案：直接选中该档案。
- 有多份档案且本轮尚未选过：展开档案列表，要求用户明确选择一份。
- 本轮已经选过：再次打开时保留本轮选择。

系统不自动把收藏、验证次数或更新时间最高的档案设为首选。同一个实体耗材在一次
配色选择中只能使用一份作者档案；不同实体耗材仍可多选。

## 收藏

每份作者档案都有独立星标，用户可收藏零个、一个或任意多个档案。收藏行为与本次耗材
勾选互不影响，也不需要点击弹窗底部“完成”才生效。

`收藏`标签只显示包含已收藏档案的实体耗材卡片；展开后只显示已收藏的档案行。如果
同一实体耗材收藏了多份作者档案，这些档案仍归在同一卡片中。

收藏使用稳定的 `material_profile_id` 持久化。旧档案在尚无稳定标识时，暂用其
`directory_name` 作为兼容键；后端补齐稳定标识后应提供一次无损键迁移。删除或无法
读取的档案收藏键可以保留但不显示，不能导致选择器报错。

收藏与最近使用记录沿用前端持久化模式，分别保存为有版本号的本地数据；第一版不新增
账号或云端收藏接口。以后若增加账号同步，必须保留用户已经收藏的全部档案，不能把多
收藏关系压缩成单一“首选”。

## 跨材料类型选择

用户始终可以自由混选不同类型。界面只提示，不替用户做决定。

当已选档案包含两个或以上明确材料族，或“未分类”与任一明确材料族并存时，在内容区
底部和已选摘要附近立即显示琥珀色提示。提示说明当前选中类型，例如：

> 当前选择包含 PLA 4 项、PETG 1 项。

点击“完成”时打开二次确认：

**标题：** 确认混合耗材类型？

**正文：** 当前选择包含 PLA 4 项、PETG 1 项。请确认喷嘴温度、热床温度和层间
粘结符合你的打印方案。

**操作：**

- 返回调整
- 仍然使用

文案保持客观，不使用针对新手的倾向性建议。用户点击“仍然使用”后，按当前选择正常
完成；点击“返回调整”则保留所有勾选和滚动位置。

仅选择一种明确类型时不显示二次确认。仅选择多份“未分类”档案时显示轻量的类型未知
提示，但不触发“混合类型”确认。

## 尺寸与响应式布局

### 桌面端

- 建议宽度：`min(1080px, calc(100vw - 48px))`
- 建议最大高度：`min(820px, calc(100vh - 48px))`
- 品牌栏宽度：约 190–220px
- 内容区：两列，列间距 12–16px
- 标题、筛选、结果和底部操作栏保持固定；品牌栏与结果区独立滚动

固定区域不能互相遮挡，滚动到长列表底部时仍能看到已选数量、清除选择和完成按钮。

### 紧凑窗口与移动端

宽度小于约 760px 时：

- 弹窗接近全屏显示并保留安全边距。
- 品牌侧栏折叠为“品牌”下拉筛选。
- 耗材卡片改为单列。
- 材料类型标签可横向滚动，但当前标签始终可见。
- 作者档案在卡片内纵向展开，不使用横向表格。
- 底部操作栏固定并适配安全区。

## 数据契约

耗材库列表和档案元数据增加以下可选字段，旧客户端与旧档案仍可读取：

| 字段 | 含义 |
| --- | --- |
| `material_type` | 规范化材料类型，例如 `PLA`、`PETG`、`ABS` |
| `material_type_source` | 类型来源；显式档案为 `archive`，旧名称兼容为 `legacy_name` |
| `material_product_id` | 同一实体耗材跨作者档案共享的稳定标识 |
| `material_profile_id` | 每份作者档案的稳定唯一标识 |
| `contributor_name` | 档案贡献者的展示名称 |

新增字段必须进入后端 schema、列表 API、前端类型和档案读写路径。字段缺失时：

- `material_type` 缺失：进入“其他”，标记“未分类”。
- `material_product_id` 缺失：该档案独立成组。
- `material_profile_id` 缺失：以前端兼容键识别收藏。
- `contributor_name` 缺失：显示“未知作者”，不从名称中强制拆分。

现有 `directory_name`、颜色值、ΔE、品牌和名称继续保留。完成选择后仍向现有下游流程
提交档案目录标识，避免本次 UI 改造改变生成语义。

## 状态与异常

- 弹窗内的勾选属于暂存状态，只有“完成”或混合类型确认后的“仍然使用”才提交。
- 关闭弹窗或按 Escape 放弃本轮勾选变化，但收藏变更已经独立持久化。
- 加载失败时保留搜索与筛选框架，显示可重试错误，不把空数据误报为“没有耗材”。
- 搜索无结果、当前品牌无结果、收藏为空和全部数据为空使用不同空状态文案。
- 数据刷新后若已选档案消失，应移除该项并用非阻塞提示告知用户。
- 单个旧档案字段异常不能阻断整个列表，其不可用信息以降级标签展示。

## 可访问性

- 主弹窗使用 `role="dialog"`、`aria-modal="true"`，并关联标题和说明。
- 二次确认使用独立的警示对话框语义。
- 打开时聚焦搜索框，Tab 焦点限制在弹窗内；关闭后恢复到“选择耗材”按钮。
- Escape 先关闭二次确认，再关闭主弹窗；展开区支持键盘操作。
- 类型和品牌筛选暴露明确的选中状态，不能只依赖颜色。
- 收藏按钮使用包含耗材与作者名称的可访问标签。
- 即时混选提示使用可被辅助技术感知、但不会反复打断输入的状态区域。

## 验证

### 自动化

1. 旧 API 响应缺少新增字段时仍可加载，并进入正确降级状态。
2. 只有相同 `material_product_id` 的档案会归组，名称相似不会误合并。
3. 品牌导航展示全部品牌，不存在“更多品牌”分组；大小写重复品牌只合并展示。
4. 类型、品牌、名称和作者搜索都能返回正确结果。
5. 用户可以收藏同款耗材的任意多份档案，刷新后收藏仍存在。
6. 收藏不会改变当前选择，也不会自动选择某份档案。
7. 最近使用只在成功提交后更新排序，不会自动选择或收藏档案。
8. 多档案耗材必须明确选择一个档案，同一实体耗材不会同时提交两份档案。
9. PLA 与 PETG 混选后立即出现提示，点击完成出现二次确认。
10. 返回调整保留选择，仍然使用提交原有档案目录标识。
11. 单一材料类型不出现二次确认；未分类组合按设计降级。
12. 桌面双列、紧凑窗口单列以及固定底栏在边界尺寸下没有遮挡。
13. 对话框焦点循环、焦点恢复、Escape、星标和档案选择均可用键盘完成。
14. 单档案和多作者档案的选中外层卡片使用相同的淡蓝底、内描边与轻阴影，未选中卡片
    不带这些样式。
15. 单档案卡片不显示圆圈或对勾；主动选中只触发一次约 180ms 蓝光过渡，初始已选、
    取消选择和减少动态效果模式均不播放。

非 watch 前端测试继续通过 `python scripts/run_vitest.py <args>` 执行。

### 真人浏览器流程

使用至少包含 PLA、PETG、同款多作者档案和大小写重复品牌的真实耗材库，验证：

1. 打开选择器后先看到清晰的类型标签、完整品牌栏和双列卡片。
2. 搜索作者并收藏两份同款耗材档案，关闭再打开后收藏仍存在。
3. 分别从 PLA 与 PETG 中选择档案，确认即时提示与二次确认文案正确。
4. 返回调整后继续修改，再选择“仍然使用”，确认主界面已选数量和档案身份正确。
5. 缩窄浏览器窗口，确认品牌下拉、单列卡片和固定操作栏可完整操作。
6. 只用键盘完成搜索、筛选、展开、收藏、选择、确认和关闭。
7. 将选中与未选中卡片并排比较，确认整卡状态清晰但不过强，鼠标悬浮时边框不叠加，
   且卡片不发生缩放或位移。
8. 反复选择、取消并重新选择一张单档案卡，确认每次主动选中只播放一次短暂蓝光，
   右侧不再出现圆圈或对勾，收藏星标仍可独立操作。

## 验收标准

- 用户无需在一列长列表中辨认材料类型与品牌。
- 全部品牌平等、完整、可搜索地呈现。
- 同款多作者档案不再重复占据主列表，但每份档案可独立选择和收藏。
- 用户可以收藏任意数量的档案，系统不替用户排序或推荐。
- 混选不同材料类型始终被明确提示，但不会被系统禁止。
- 旧档案不会因名称猜测而被错误归组，现有生成流程接收的档案身份保持不变。
- 用户通过整张卡片即可识别选中状态，界面不再重复显示圆圈或对勾，且一次性选中特效
  不会与悬浮、焦点或持续动画混淆。
