# LUM-20260717 Region Scope Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Every implementation task follows test-driven development and receives spec-compliance and code-quality review before the next task starts.

**Goal:** Ensure a connected-region colour edit remains spatially scoped in standard and large-format generation, so the downloaded 3MF/ZIP matches the correct preview without recolouring unrelated shapes that share a LUT colour.

**Architecture:** Treat `replacement_regions` as global colour mappings only. Keep spatial edits in the preview cache (`matched_rgb`, `mask_solid`, and `material_matrix`), validate those artifacts whenever the request says spatial edits exist, then reuse them in native SVG tiling and crop them together for raster/high-fidelity tiling. Reuse the existing vector projection helper before tile slicing, preserve recipe-override precedence in raster tiles, and fail closed instead of silently generating from stale or malformed cache state.

**Tech Stack:** Python 3, FastAPI, NumPy, Pillow, Shapely/vector engine, React 19, TypeScript, Zustand, Vitest/fast-check, pytest
