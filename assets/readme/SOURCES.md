# README image sources

These seven files are unchanged copies from the existing public Lumina-Layers
README update in [PR #243](https://github.com/lumina-layer-studio/Lumina-Layers/pull/243),
at commit `5533021f81ff1b841f4f172bd57c3fc87dcb8815`.

The upstream README identifies the gallery as physical prints from 1.x and 2.0
users and states that the community photographs are displayed with permission.
Copyright in the depicted artwork remains with its respective creator. Reuse
here continues that project presentation; the root software license is not a
new license grant for the photographs or depicted artwork.

No image was generated, retouched, cropped, or recompressed for this update.
The original colour labels are retained. The gallery is not a test fixture or
a claim that every displayed object has a built-in structural generator.
